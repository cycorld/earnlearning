# 투자 내역을 현재 강의실별로 분리하기

## 무엇을 했나요?

투자 화면의 포트폴리오와 배당 내역이 현재 선택한 강의실의 회사만 보여주도록 수정했습니다. 투자금도 해당 회사가 속한 강의실 지갑에서만 출금하도록 명확히 했습니다.

## 왜 필요한가요?

한 사용자가 여러 수업에 참여하면 과거 수업의 투자 내역이 현재 수업 화면에 섞여 보일 수 있었습니다. 수업별 모의 경제가 독립적으로 운영되려면 조회와 자금 이동 모두 같은 강의실 경계를 지켜야 합니다.

## 어떻게 확인했나요?

두 강의실에 가입한 사용자가 A 강의실에서 투자·배당을 받은 뒤 B 강의실로 전환하는 통합 테스트를 추가했습니다. B에서는 A의 포트폴리오·배당이 보이지 않고, A로 돌아오면 다시 보이는지 검증합니다.

## 사용한 프롬프트

> 투자 페이지 내 포트폴리오의 강의실 구분을 확인하고, 동일 문제를 찾아 수정·검증·배포해 주세요.

## 배운 점

목록 필터만 고치면 화면은 정상처럼 보여도 실제 출금 지갑이 잘못 선택될 수 있습니다. 조회와 쓰기 경계를 함께 점검해야 완전한 격리가 됩니다.
