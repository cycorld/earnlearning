# 207. 로그인·회원가입 폼 및 루트 언어 태그 UI/UX 무결성 개선

## 무엇을 했나요?

개밥먹기(dogfood) 7대 게이트 실측 검수를 통해 발견된 루트 HTML 언어 불일치, 로그인 폼 용어 혼선, 회원가입 모바일 인풋 하단 클리핑을 수정했습니다.

## 왜 필요한가요?

- 루트 HTML이 `<html lang="en">`으로 지정되어 있어 스크린리더 및 번역 팝업 오작동이 유발되었습니다.
- 로그인 폼의 체크박스가 `이메일` 입력 필드와 달리 `아이디 저장`으로 표기되어 혼동이 있었습니다.
- 모바일 회원가입 화면에서 카드 본문과 푸터 구분선 간 패딩 부족으로 학번 입력 필드 하단 테두리가 겹쳐 클리핑되는 현상이 있었습니다.

## 어떻게 안전하게 만들었나요?

- `frontend/index.html`: `<html lang="ko">`로 정규화.
- `LoginPage.tsx` & 테스트: `아이디 저장`을 `이메일 저장`으로 일치.
- `RegisterPage.tsx`: `CardContent`에 `pb-4`를 추가하여 모바일 뷰포트에서 입력 테두리와 푸터 간 안전 여백 확보.
- 프론트엔드 Vitest 309개 테스트 전수 통과 확인.

## 검증

Vitest 309개 단위 테스트 통과 및 로컬 7-Gate Dogfood QA (데스크톱, 모바일, 0px 오버플로우, 콘솔 0건, System 1 시각 판정, UX 인터랙션, 다국어 텍스트 무결성) 전수 PASS.

## 사용한 프롬프트

earnlearning 개밥먹기로 개선해줘
