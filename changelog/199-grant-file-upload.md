# 정부과제 파일 첨부 범위 확인

## 무엇을 했나요?

정부과제 지원서에서도 일반 게시판과 같은 파일 형식을 첨부할 수 있도록 회귀 테스트를 추가했습니다.

## 왜 필요한가요?

두 화면은 같은 마크다운 편집기를 사용하지만, 이후 변경으로 정부과제에서 파일 첨부가 빠지지 않도록 자동 검증이 필요했습니다.

## 어떻게 확인했나요?

정부과제 지원 화면을 열고 파일 선택 입력의 허용 형식이 일반 게시판 공통 편집기와 같은지 테스트했습니다. 프론트엔드 빌드와 백엔드 스모크 테스트도 통과했습니다.

## 사용한 프롬프트

> 언러닝 정부과제 제출시 파일 업로드 가능하게 해주는데 일반게시판 파일업로드 확장자 동일하게 해줘

## 배운 점

이미 공통 컴포넌트가 요구사항을 충족한다면 코드를 중복하기보다 그 연결을 테스트로 고정하는 편이 더 안전합니다.
