# 같은 강의실 학생에게 새 메시지 보내기

## 무엇을 했나요?

메시지 목록 화면에 `메시지 쓰기` 버튼을 추가했습니다. 버튼을 누르면 현재 강의실 학생 목록을 보고 이름·학과·학번으로 검색한 뒤 바로 대화를 시작할 수 있습니다.

## 왜 필요한가요?

기존에는 상대방 프로필을 먼저 찾아가야만 메시지를 보낼 수 있었습니다. 이제 메시지 화면 안에서 수신자를 찾고 대화를 시작할 수 있어 흐름이 짧고 명확해졌습니다.

## 어떻게 만들었나요?

서버가 현재 강의실의 승인된 학생만 최소 정보로 반환하도록 별도 API를 만들었습니다. 본인과 다른 강의실 사용자는 제외하고, 일반 사용자는 해당 강의실 구성원인지 확인합니다. 화면에서는 검색 결과를 선택하면 기존 대화 화면으로 이동하므로 검증된 메시지 전송 기능을 그대로 재사용합니다.

자동 테스트와 프로덕션 빌드를 통과시켰고, 임시 로컬 계정과 강의실을 만들어 Agent Browser로 학생 검색부터 실제 메시지 전송까지 확인했습니다.

## 사용한 프롬프트

> 메시지 화면에서 메시지 쓰기 버튼 추가하고 해당 교실 학생들 리스트와 검색으로 메시지 보낼 수 있도록 해줘

## 배운 점

화면에서 목록만 제한해서는 다른 강의실 정보 노출을 막을 수 없습니다. 서버에서 강의실 멤버십과 학생 범위를 함께 검증해야 UI와 보안 정책이 일치합니다.
