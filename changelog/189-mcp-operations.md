# MCP 운영 도구 P0~P2 확장

## 무엇을 했나요?

EarnLearning의 기존 HTTP API를 MCP에서 조회·호출할 수 있도록 운영 도구 목록을 확장했습니다. 관리자 현황, 강의실·지갑·회사·게시물·투자 조회와 승인형 및 일반 사용자 변경 작업을 하나의 등록표에서 관리합니다.

## 왜 필요한가요?

AI 에이전트가 새 서버 기능을 만드는 대신 이미 검증된 API를 재사용하면 권한과 업무 규칙이 한곳에 유지됩니다.

## 어떻게 안전하게 만들었나요?

URL은 등록된 경로만 사용하고 경로 ID는 양의 정수만 허용합니다. query와 JSON body도 도구별 허용 목록만 전달합니다. 모든 변경 도구는 `confirm` 값이 호출 도구명과 정확히 같아야 하며, 이 값은 API body에서 제거됩니다. 응답 크기 제한, redirect 차단, SSRF 방어도 유지했습니다.

OAuth를 거부하는 DM 전송·메일, 안전한 파일 경로 정책이 없는 multipart 업로드, impersonate·일괄 이자·배당·전체 재색인 같은 위험 작업은 노출하지 않았습니다.

## 사용한 프롬프트

“최신 branch feat/189-mcp-operations에서 P0~P2 MCP 도구 확장을 최소 diff로 구현하고 테스트하라.”

## 배운 점

도구 수가 늘어도 method·path·입력 허용 목록을 데이터로 관리하면 중복 코드를 줄이면서 신뢰 경계를 명확하게 유지할 수 있습니다.
