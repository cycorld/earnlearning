# 로컬 운영 데이터 보관 정책

이 폴더는 저장소와 함께 사용하는 **로컬 운영 자료, 생성물, 민감정보**를 보관하는 전용 공간이다. 이 README만 Git으로 추적하며, 폴더 안의 다른 내용은 공개 저장소에 커밋하지 않는다.

## 권장 하위 폴더

- `generated/`: 자동 생성 결과물과 임시 산출물
- `whitepaper-2026/`: 로컬 문서 작업 자료
- `kanban-evidence/`: 칸반 작업 증빙과 점검 결과
- `worklogs/`: 로컬 작업 기록

필요하면 목적이 분명한 다른 하위 폴더를 만들 수 있다. 파일명과 내용에도 개인정보, 자격 증명 등 민감정보가 노출되지 않도록 주의한다.

## 이동 및 복구 원칙

- 저장소 루트의 기존 `generated/`, `whitepaper-2026/`, `WORKLOG.md`, `.kanban-evidence-*/` 자료는 각각 알맞은 권장 하위 폴더로 **이동**한다.
- 원본 복구가 필요하면 이동 전 로컬 경로 또는 별도 로컬 백업에서 가져온 뒤 `_local-ops/` 아래에 둔다.
- 대용량 자료는 복사해 중복을 만들기보다 위치와 여유 공간을 확인한 후 이동한다.
- 운영 자료는 Git에 없다는 이유로 불필요한 자료가 아니다. 정리 과정에서 **삭제하지 말고**, 보존 위치를 확인한 뒤 이동한다.
